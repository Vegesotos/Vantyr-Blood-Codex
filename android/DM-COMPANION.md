# VANTYR DM Companion

Separate Dungeon Master client for the existing VANTYR Blood Codex project.

## Android
- Android Studio module: `android/dm-app`
- App ID: `com.vantyr.dmcompanion`
- GitHub Actions: **Build VANTYR DM Companion APK**
- APK artifact: `VANTYR-DM-Companion-v1.0-Live-APK`.
- Opens `https://vegesotos.github.io/Vantyr-Blood-Codex/dm/`.
- Uses HTTPS and Supabase; player phone may be completely offline for DM initiative editing.
- Does not store any access token in the Android package. The DM pastes a full private invitation on the first run, then it is kept in the app's dedicated browser storage. Use **Forget this device** to remove it.
- This Android package is distinct from the player app (`com.vantyr.bloodcodex`).

## iPhone and iPad
An Android APK cannot install on iOS. The DM site has its own standalone web-app manifest and Apple mobile metadata.

1. Open `https://vegesotos.github.io/Vantyr-Blood-Codex/dm/` **in Safari**.
2. Tap **Share** → **Add to Home Screen** → **Add**.
3. Open the new **VANTYR DM** Home Screen icon.
4. Choose **Connect with your private invitation** and paste the complete invitation link generated by Vantyr's **DM Sync** menu.
5. Tap **Open Observer**. The invitation is saved in the installed app's local storage. The DM can switch between **Vantyr Status** and **Initiative Board** anytime.

The Home Screen app can have separate site storage from the Safari tab. If it does, opening the invitation in Safari before installing is not enough; paste the full invitation once **inside** the installed Home Screen app.

## Updating
Both clients load the live GitHub Pages DM dashboard. Web changes update when online without needing another APK or iOS installation. Native changes require a new APK (or a separately signed/distributed iOS native build).

## Data and permissions
- Character vitals/abilities are read-only to DM.
- Initiative entries/turns/rounds can be edited by DM via token-authenticated Supabase RPCs.
- If the player phone loses power, the DM can still edit the initiative board and read last-synced character status, provided the DM device has internet and Supabase is available.
- The invite URL is confidential. If compromised, replace or revoke it via the player's DM Sync menu.
- This APK is a debug/test package, not a Play Store production-signed release.
